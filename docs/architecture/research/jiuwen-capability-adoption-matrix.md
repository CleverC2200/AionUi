## 口径

- **Aion 引入优先级**：`P0` 是契约或可靠性前置，`P1` 是下一批产品能力，`P2` 是增强，`暂缓` 是依赖或风险尚未满足。
- **向 openJiuwen 投稿接受概率**：`高/中/低` 是基于 live 代码、Issue/PR 占用和评审规则的推断，不是维护者承诺；`不适用` 表示已实现、已占坑、状态漂移、只属于 Aion，或没有原子上游空缺。
- **两列不可互推**：例如 embedding 指纹对 Aion 是 `P1`，但 Jiuwen develop 已实现主链路，所以投稿概率是`低`；MCP 生命周期对 Aion 是 `P0`，但 Jiuwen 已有大型 WIP，另开 PR 仍是`低`。
- **“可抄”默认指机制、契约和交互借鉴**：直接复制代码仍要逐仓核验许可证与 NOTICE。已核验的主仓及多数相邻仓声明 Apache-2.0；本次 DeepSearch 快照未发现可识别的 LICENSE，按“只参考设计，不复制代码”处理。

官方投稿入口是 **GitCode**：Fork 后向 `develop` 提 PR，关联 Issue、说明测试，UI 变更附截图，并经过 CI 和至少两位 Committer 审查。GitHub 是同步镜像，Open 状态不是“官方已受理、无人占坑或尚未修复”的充分证据。见官方 [`贡献指南`](https://github.com/openJiuwen-ai/jiuwenswarm/blob/91c9f367a8308ac95f9b688905fa76f3eabd55e7/docs/zh/%E8%B4%A1%E7%8C%AE%E6%8C%87%E5%8D%97.md#L36-L90) 和 [`审查流程`](https://github.com/openJiuwen-ai/jiuwenswarm/blob/91c9f367a8308ac95f9b688905fa76f3eabd55e7/docs/zh/%E8%B4%A1%E7%8C%AE%E6%8C%87%E5%8D%97.md#L166-L178)。
