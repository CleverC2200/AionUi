03 · GEAUi 企业助手主旅程

目录同步GEA/AionCore 返回受管 Assistant 投影
受管详情身份、规则、权限、必需能力只读
辅助增量只提交策略允许的 Skill/MCP 增量
原子准备客户端创建会话只消费 opaque preparation
运行与待处理请求回到原会话、原 Turn、原消息
结构化交付完成回执必须引用通过验证与底层证据
防呆与权限边界
企业生产 MCP、核心 Skill、Agent、指令、权限和默认配置不能被本地替换。辅助增量使用 expected revision 与稳定 idempotency key；结果未知时进入“需要核验”，不自动重试。
目录兼容
企业空目录、首次失败、last-good、乱序响应、最低客户端版本、暂停/撤回都保留明确状态；不会伪造官方助手，也不会让过低版本继续启用或聊天。

04 · Team 分支

会话仍是主界面

默认进入当前成员单会话；成员轨道表达负责人、状态、阻塞和待处理。Board/Activity 只保留为按需诊断。

同一交付协议

负责人聚合成员 Conversation Record；默认按当前成员筛选，可清除筛选回到全队。原 record ID、producer、Turn/Task 与 deliverable revision/replaces 链可见。

同一待处理协议

Team 请求携带 team、slot、conversation、turn/message，顶层待处理入口返回原成员和原消息。

窄屏收敛

窄屏强制单成员视图；不会从 localStorage 恢复并行布局，资源检查器按需展开且不遮挡发送区。

05 · 错误恢复路线

场景客户端行为结果
目录首次失败 / 空目录原位置错误或企业空状态；允许就地重试不伪造能力
目录离线显示 last-good revision 与待同步状态新会话仍由 AionCore 裁决
准备取消 / 竞态取消立即结束；晚到 generation 不创建会话无半配置会话
conflict / expired / forbidden采纳回执中的权威 request/version；旧命令不可再次提交来源权威收敛
WS 重连重新 GET pending 与成员 records未决请求可恢复
unknown external write保留草稿并锁定重试，要求先核验防止重复生产写
record gap / 无效证据链停止应用增量并回源 snapshot；拒绝悬空/循环证据无证据不宣称完成

09 · 风险与验收边界

当前没有 GEA 企业测试租户，因此企业身份切换、真实策略拒绝、生产 MCP 写入只验证客户端契约 fixture；本交付不声称执行过任何生产业务写入。

桌面范围

已验证 macOS 当前架构 Electron 生产 bundle；未生成签名安装包，Windows/Linux 原生打包交给对应 CI。

上游兼容

官方代码是持续合并主线；企业能力仅经过 common adapter / HTTP/WS 契约，不新增绕过层的 Electron IPC。

发布边界

当前工作只在本地分支与个人仓库来源工作树中；未推送、未创建公开 PR，也未修改原基线工作树。

后续 GEA 实现

GEA 需按目录、扩展、准备、请求和记录 V1 契约实现；服务端策略错误直接返回定义错误，由客户端原位展示。
